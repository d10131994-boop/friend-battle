# Democracy Merge V2 — графические ресурсы одиночного режима

Этот каталог предназначен **только для одиночного режима**. Не заменяйте им персонажей многопользовательского режима.

## Персонажи

Все десять PNG загружены в этот каталог и проверены: формат PNG RGBA, разрешение 384×448 пикселей, имена соответствуют таблице:

| Файл | Уровень | Внешний вид |
| --- | --- | --- |
| `level-01.png` | 1 | Крестьянин с вилами |
| `level-02.png` | 2 | Фермер в соломенной шляпе |
| `level-03.png` | 3 | Землевладелец в шляпе с красным пером |
| `level-04.png` | 4 | Рыцарь с картой |
| `level-05.png` | 5 | Вельможа в фиолетовом |
| `level-06.png` | 6 | Вельможа в синем плаще |
| `level-07.png` | 7 | Воин в сине-золотом |
| `level-08.png` | 8 | Вельможа в красно-золотом со свитком |
| `level-09.png` | 9 | Полководец в красном плаще |
| `level-10.png` | 10 | Король со знаменем |

**Проверенный формат:** PNG RGBA, 384×448 пикселей. Код `CharacterPortrait.tsx` использует пути `/democracy-merge/solo/level-XX.png` и автоматически показывает номер уровня, если изображение не найдено.

## Прочие изображения

- `../tools/` — SVG четырёх инструментов (saw, storage, swap, replace).
- `../obstacles/` — SVG трёх действующих препятствий (barricade, police, rock).

Замену изображений проводите без изменения типов, стоимости и игровой логики. После загрузки PNG проверьте поле, текущего и следующего персонажей, а также отображение на мобильном экране.
