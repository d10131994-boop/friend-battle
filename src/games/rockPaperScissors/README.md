# Камень, ножницы, бумага

Классическая игра для одного игрока или двух игроков по сети.

## Правила

- Матч идёт до трёх побед.
- Каждый раунд начинается с трёхсекундного выбора жеста.
- Камень, ножницы и бумагу можно выбирать до окончания таймера; если игрок ничего не выбрал, засчитывается камень.
- После выбора оба жеста раскрываются на четыре секунды.
- Затем на четыре секунды показывается результат раунда и текущий счёт.
- Победитель раунда получает одно очко. При ничьей очки не начисляются.
- Матч заканчивается, когда один игрок набирает три очка.

В одиночном режиме компьютер выбирает жест случайно. Его имя на итоговом экране зависит от жеста, который он выбирал чаще всего: бумага — Влад, ножницы — Эдвард, камень — Дуэйн. Если несколько жестов встречаются одинаково часто, имя выбирается случайно среди них.

## Мультиплеер

Для матча нужны ровно два игрока. Выборы скрыты друг от друга до раскрытия. Отсчёт и переходы фаз контролируются сервером; отсутствие выбора к дедлайну превращается в камень. После завершения матча результат показывается обоим игрокам, затем они возвращаются в общую комнату.
